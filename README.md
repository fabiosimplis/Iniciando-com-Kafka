# Iniciando Com Kafka
[![NPM](https://img.shields.io/npm/l/react)](./LICENSE) 

# Sobre o projeto

Iniciando com Kafka é um conjunto de serviço back end web construída em conjunto ao curso **Alura**, da plataforma [Kafka](https://www.alura.com.br "Site da Alura"), para estudo de java com Kafka.
A aplicação simula varios serviços de um e-commerce como, envio de email, recebimento de pedidos, log e sistema anti-fraude


# Tecnologias utilizadas
## Back end
- Java
- Kafka
